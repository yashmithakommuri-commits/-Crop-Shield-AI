
# 🌱 Crop Shield AI

### Early Prediction and Management of Crop Disease and Pest Infestation

**Project ID:** SIH26131

## About the Project
Crop Shield AI is a farmer-oriented mobile application designed to support early identification and management of crop diseases and pest infestations.

## Key Features
- Image-based crop disease prediction.
- Offline TensorFlow Lite model integration.
- Gallery image selection.
- Crop-specific prediction handling.
- Farmer-friendly language selection.
- Crop management and history.
- Weather and crop-based risk prediction.
- Alerts and notifications.

## Technologies Used
- Flutter
- Dart
- TensorFlow Lite
- Python (model development ecosystem)

## Supported Crop Categories
- Tomato
- Potato
- Bell Pepper

## Project Objective
To make AI-assisted crop disease identification more accessible to farmers through a mobile application.
